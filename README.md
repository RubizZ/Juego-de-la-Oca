# Juego de la Oca
Juego desarrollado en la asignatura de "Fundamentos de Programación I" de Ingeniería Informática en la Universidad Complutense de Madrid

## Tecnologías
El juego esta desarrollado en C++ y hace uso de la consola para mostrar el tablero

## Como jugar
- Utilizar Visual Studio para abrir la solución, y ejecutar el proyecto, o compilar el archivo "Source.cpp" y ejecutarlo.
- Al iniciar, puedes comenzar una nueva partida, o cargar una partida guardada (se proporciona el archivo "partidas.txt" vacío para usarlo como archivo de guardado)
- Al seleccionar nueva partida, se pide el número de jugadores (de 2 a 4), y el tablero (se proporciona el archivo "tablero.txt" como tablero)
- En la partida, cada jugador pulsa ENTER para tirar los dados en su turno
- Si se quiere guardar la partida para luego, se escribe "SALIR" en la consola, y se escribe el nombre del archivo en el que se guardará la partida
